# frontend

The Vite + React app that hosts the challenges. See the [repo README](../README.md) for the curriculum and workflow.

```bash
pnpm install
pnpm dev              # challenge browser at http://localhost:5173
pnpm new 42           # scaffold src/challenges/042-<slug>/
pnpm lint
pnpm build            # the only thing that type-checks
pnpm sync:curriculum  # regenerate the challenge index from curriculum/challenges.json
```
